# List a plot's components and their numbers

Shows how the numbers in \`animate\` map onto the plot's components for
each \`scope\`. Needs a plot made with \[steps()\] (or the plot code
itself).

## Usage

``` r
plot_components(p)
```

## Arguments

- p:

  A plot made with \[steps()\], or plot code.

## Value

A data frame with one row per component, invisibly; it is printed.
